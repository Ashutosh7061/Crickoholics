# Crickoholics


A simple and extensible REST API server built using Flask, MySQL, HTML, CSS, and Bootstrap.  
This project provides IPL team, player, and match data and can be extended with analytics and machine-learning-based predictions.

---

## Features

- REST API for teams, players, matches, and statistics  
- MySQL database integration  
- Clean UI using HTML, CSS, Bootstrap  
- Modular Flask project structure  
- Error-handled routes  
- Easily extendable for analytics and ML predictions  
- Suitable for deployment on Render or AWS
